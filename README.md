# Scriptrail

**Track your writing. See your progress. Stay consistent.**

Scriptrail is a Chrome extension that runs quietly in the background while you write in Google Docs. It logs every session automatically -- words written, time spent -- and shows you charts so you can see your writing habits over time.

No setup. No accounts. No distractions. Just open a doc and start writing.

---

## Who it's for

- **Writers** building a daily word count habit
- **Students** tracking essays, dissertations, and assignments
- **Teachers** monitoring their own lesson planning and content creation
- **Professionals** who write reports, proposals, or documentation regularly

If you write in Google Docs and want to know how much you're actually writing, Scriptrail is for you.

---

## What it does

- Tracks **words written per session** automatically
- Logs **time spent writing** in each document
- Displays **charts** of your writing activity over time
- Works on any Google Doc you have edit access to
- Stores all data locally on your device -- nothing is sent anywhere

## Installation

### From the Chrome Web Store *(coming soon)*

1. Go to the Chrome Web Store listing *(link coming soon)*
2. Click **Add to Chrome**
3. Open any Google Doc you have edit access to
4. Scriptrail starts tracking automatically

### Manual install (Developer Mode)

1. Clone this repo:
   ```bash
   git clone https://github.com/Achiever10123/scriptrail.git
   ```
2. Open Chrome and go to `chrome://extensions`
3. Enable **Developer mode** (toggle in the top right)
4. Click **Load unpacked** and select the cloned folder
5. Open a Google Doc -- Scriptrail is now active

---

## How it works

Once installed, Scriptrail runs in the background whenever you have a Google Doc open. It detects your edit activity, counts words written during the session, and logs the duration. All of this is stored locally using Chrome's storage API -- no external servers, no accounts required.

Open the extension popup at any time to see your stats and charts.

---

## Requirements

- Google Chrome or any Chromium-based browser
- A Google account with edit access to the docs you want to track

---

## Privacy

Scriptrail does not collect, transmit, or store your data anywhere outside your own browser. Everything stays on your device.
